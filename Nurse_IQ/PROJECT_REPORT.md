## 🛠️ التقنيات المستخدمة

### Backend
- **ASP.NET Core MVC** (.NET 9.0)
- **Entity Framework Core** (ORM)
- **SQL Server** (قاعدة البيانات)
- **ASP.NET Core Identity** (المصادقة والتفويض)

### Frontend
- **HTML5** & **CSS3**
- **JavaScript** & **jQuery**
- **Bootstrap 5** (UI Framework)
- **Bootstrap Icons**

### Architecture Patterns
- **Repository Pattern** (نمط المستودع)
- **Unit of Work Pattern** (نمط وحدة العمل)
- **Service Layer Pattern** (طبقة الخدمات)

## 🚀 خطوات التشغيل

### 1. متطلبات النظام
- .NET 9.0 SDK
- SQL Server (LocalDB أو Express)
- Visual Studio 2022 أو VS Code

### 2. تثبيت الحزم المطلوبة
```bash
dotnet add package Microsoft.EntityFrameworkCore.Tools
```

### 3. إنشاء Migration
```bash
dotnet ef migrations add InitialCreate
```

### 4. تحديث قاعدة البيانات
```bash
dotnet ef database update
```

### 5. تشغيل المشروع
```bash
dotnet run
```

### 6. الوصول للمنصة
افتح المتصفح وانتقل إلى: `https://localhost:5001`

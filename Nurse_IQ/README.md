# NursingIQ - منصة التمريض الذكية

## نظرة عامة
منصة تعليمية متخصصة في التمريض تهدف إلى تطوير مهارات الممرضين والممرضات من خلال الدورات التدريبية والمحتوى التعليمي المتخصص.

## الميزات الرئيسية
- 🎓 دورات تعليمية متخصصة في التمريض
- 📚 مقالات طبية متنوعة
- 🏥 تدريبات عملية في المستشفيات
- 💊 قاعدة بيانات شاملة للأدوية والمصطلحات الطبية
- 🎯 اختبارات تفاعلية
- 📹 فيديوهات تعليمية
- 🏆 دبلومات مهنية معتمدة
- 💬 منتدى للنقاشات الطبية

## التقنيات المستخدمة
- **Backend**: ASP.NET Core MVC (.NET 9.0)
- **Database**: SQL Server مع Entity Framework Core
- **Authentication**: ASP.NET Core Identity
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Architecture**: Repository Pattern, Unit of Work Pattern

## متطلبات التشغيل
- .NET 9.0 SDK
- SQL Server (LocalDB أو Express)
- Visual Studio 2022 أو VS Code

## خطوات التشغيل

### 1. استنساخ المشروع
```bash
git clone [repository-url]
cd NursingIQ/Backend/Nurse_IQ
```

### 2. تحديث قاعدة البيانات
```bash
dotnet ef database update
```

### 3. تشغيل المشروع
```bash
dotnet run
```

### 4. الوصول للمنصة
افتح المتصفح وانتقل إلى: `https://localhost:5001`

## هيكل المشروع

```
Backend/Nurse_IQ/
├── Controllers/          # وحدات التحكم
├── Data/                # قاعدة البيانات والبيانات الافتراضية
│   ├── Config/          # تكوينات Entity Framework
│   ├── AppDbContext.cs  # سياق قاعدة البيانات
│   ├── SeedData.cs      # البيانات الافتراضية
│   └── DbInitializer.cs # تهيئة قاعدة البيانات
├── Models/              # نماذج البيانات
├── Repoitory/           # نمط المستودع
├── Service/             # طبقة الخدمات
├── UnityOfWork/         # نمط وحدة العمل
├── Views/               # واجهات المستخدم
└── Enums/               # التعدادات
```

## التطوير

### إضافة بيانات جديدة
1. أضف البيانات في `SeedData.cs`
2. حدث `DbInitializer.cs` إذا لزم الأمر
3. أعد تشغيل المشروع

### إضافة نموذج جديد
1. أنشئ النموذج في `Models/`
2. أضف DbSet في `AppDbContext.cs`
3. أنشئ تكوين في `Data/Config/`
4. أضف Migration جديد
5. حدث البيانات الافتراضية
